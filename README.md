# AIDP

AIDP 是一个开源优先、可私有部署的轻量智能决策平台。项目首先帮助没有线上管理系统的客户，把制度、流程、表单、台账等原始材料通过多轮 Agent 确认转化为标准流程、本体、结构化记录、知识和指标，再用尽可能少的基础设施打通“Skills/MCP/规则/工具—智能体运行—证据与审计”闭环。

当前阶段：产品定义。

## 核心约束

- 模块化单体优先，不以微服务数量衡量平台能力。
- 默认只依赖 PostgreSQL，避免为单项能力引入独立中间件。
- Docker Compose 一键启动，单机即可完成开发、演示和小规模使用。
- 数据、规则、工具调用和智能体结论均可追溯。
- 平台核心代码和必选依赖采用开源方案；模型既可接云端 API，也可接本地 OpenAI-compatible 服务。
